# IT Quiz (SwiftUI)

SwiftUI-ремейк консольной IT-викторины на C++ ([оригинал](https://github.com/sewagote/it-quiz)) — обучающий pet-проект для практики Swift и SwiftUI.

## Возможности

- Выбор языка вопросов (русский/английский) через флаги стран
- Выбор категории (железо, сети, программирование, операционные системы) и сложности (легко/средне/сложно)
- Вопросы с несколькими вариантами ответа, случайный порядок при каждой игре
- Подсветка ответа: верный вариант всегда показывается зелёным, неверный выбор — красным
- Подсчёт очков, текущего и максимального стрика
- Экран результатов по завершении игры
- Возможность сыграть ещё раз с сохранёнными настройками
- Полная локализация интерфейса на русский и английский

## Технологии и архитектура

- Swift, SwiftUI
- Архитектура MVVM: `Question`/`Category`/`Difficulty`/`Language` — модели данных, `QuizViewModel` — состояние игры, Views — экраны
- Навигация между экранами через `NavigationStack`
- Вопросы хранятся в JSON (`questions_ru.json`/`questions_en.json`) в `Resources`, грузятся через `QuestionLoader`

## Структура проекта

```
it-quiz-swiftui/
├── Models/       — Question, Category, Difficulty, Language, UIStrings
├── ViewModels/   — QuizViewModel (состояние текущей игры)
├── Views/        — GameSetupView, QuestionView, ResultsView и вспомогательные View
├── Services/     — QuestionLoader (загрузка вопросов из JSON)
└── Resources/    — JSON-файлы с вопросами
```

## Запуск

1. Склонировать репозиторий
2. Открыть `it-quiz-swiftui.xcodeproj` в Xcode
3. Запустить на симуляторе или устройстве (⌘R)
